# make-lora-dataset

LoRA 学習用の `metadata.csv` を作る。音声の文字起こしは `scripts/transcribe.py`（Whisper）で行い、その結果を Claude が整える。

Claude は音声を聞けない。絵文字や聞き間違いの判断は、文字起こしのテキストの意味から推測したものになる。そのことを報告で必ず伝える。

## 手順

### 1. 確認する
- 音声のフォルダを聞く（依頼に書かれていれば、それを使う）。LoRA 学習では、学習フォルダの中の `train\` が音声のフォルダになる（例: `my_voice\train`。学習フォルダは `lora.bat init` で作れる）
- フォルダ直下に wav / flac / mp3 / ogg がなければ、そう伝えて終わる
- フォルダの中に `metadata.csv` がすでにあれば、**そこで止めて、次のどれにするかユーザーに確認する**
  - **Whisper をやり直す**: 手順 2 から進める。文字起こしは `metadata_raw.csv` に書き出し、整えた結果で `metadata.csv` を上書きする
  - **Whisper をやり直さない**: 今の `metadata.csv` の名前を `metadata_raw.csv` に変え、手順 3 から進める（それを整えて `metadata.csv` に書き出す）
  - **中止する**
- どちらの場合も、`metadata_raw.csv` がすでにあれば、そこで止めてユーザーに確認する（上書きしてよいか）

### 2. 文字起こしする
本体の `.venv` の Python で、プロジェクトのルートから次のように動かす（PowerShell）。

```powershell
& '.\Irodori-TTS\.venv\Scripts\python.exe' scripts\transcribe.py '<音声フォルダ>' --default-name metadata_raw.csv
```

- `Irodori-TTS\.venv\Scripts\python.exe` がないときは、本体が入っていない。`setup.bat` を実行するようユーザーに伝えて止める

- 結果は `<音声フォルダ>\metadata_raw.csv`（`file_name,text`）にできる。すでにあるときは、ユーザーに確認してから `--overwrite` を付ける
- `--default-name` を付けないと `transcribe_raw.csv` になるので、必ず付ける（`transcribe.py` の既定の名前は変えない）
- モデルは既定で `kotoba-tech/kotoba-whisper-v2.0`。ユーザーが別のモデルを指定したら `--model` で渡す
- 初回はモデルをダウンロードするので時間がかかる。ファイルが多いときは `timeout` を長めにする
- 失敗したら、エラーの内容をユーザーに伝えて止める（自分で何度もやり直さない）

### 3. テキストを整える
`metadata_raw.csv` を読み、1 行ずつ次のように直す。

- **句読点を付ける**: kotoba-whisper は句読点を出さないので、意味の切れ目に「、」「。」、問いかけに「？」、強い調子に「！」を付ける
  - **行の最後には「。」を付けない**（音声学習のキャプションなので不要）。例: `旦那様、朝ですよ`
  - 文の途中の「。」と、息継ぎの意味の「、」は付ける。例: `もう、起きないとキスしちゃうよ。だ、旦那様に`
  - 行の最後の「？」「！」「……」と絵文字は付けてよい
- **明らかな聞き間違いだけ直す**: 前後の文脈から確実にわかるものだけ直す。話した言葉を言い換えたり、言いよどみ（「えっと」など）を消したりしない。学習では、テキストと音声が一致していることが大事なため
- **自信がない行は直さず「要確認」にする**: 意味が通らない・途中が崩れている行は、推測で書き換えない。そのままにして、報告で「要確認」として挙げる
- **絵文字を付ける**: 喜怒哀楽がはっきりした文にだけ、[EMOJI_LIST.md](../../../EMOJI_LIST.md) の絵文字を付ける
  - 一覧にある絵文字だけを使う
  - 迷うときは付けない（合わない絵文字は学習に逆効果）
  - 1 行に付けるのは、ふつう 1 つ。その感情が出る文の終わりに付ける（例: `もう、知らない😠`）
  - 笑い声・吐息・囁きなど、テキストからはわからない音は付けない（Claude には聞こえないため）

### 4. metadata.csv を書き出す
- 場所: `<音声フォルダ>\metadata.csv`
- 形式: UTF-8（BOM なし）、1 行目は `file_name,text`。並びは `metadata_raw.csv` と同じ
- `text` に `,` や `"` が入るときは、その値を `"` で囲み、中の `"` は `""` にする
- `metadata_raw.csv` は消さずに残す（整える前のテキストと見比べられるように）

### 5. 報告する
次の内容を表にして伝える。

- ファイルごとの、元の文字起こし → 直したテキスト
- 付けた絵文字と、その理由（どの言葉から判断したか）
- 「要確認」の行と、その理由

最後に、次の 2 点を伝える。
- 絵文字と直した箇所は、テキストの意味から推測したもの。音声を聞いて確かめ、合わないものは `metadata.csv` を直してほしい
- 次の手順は `lora.bat suggest <学習フォルダ>`（30 秒超・1 秒未満の音声の確認と、学習オプションの提案）、そのあと `lora.bat latent <学習フォルダ>`（README の「LoRA 学習」を参照）。音声フォルダが学習フォルダの `train\` でないときは、`<学習フォルダ>\train\` に移す必要があることも伝える
